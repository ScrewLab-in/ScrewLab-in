# 🔩 ScrewLab

**Tinkering with open-source AI on an all-AMD PC, ricing Linux, and building tiny homelabs, one screw at a time.**

I test local AI models (LLMs, image gen, voice) on real consumer hardware and publish every number, script and config so you can reproduce it yourself. No cloud, no paid APIs, just a PC and a lot of curiosity.

### 🖥️ The test bench

| Part | What's in it |
|---|---|
| GPU | AMD Radeon RX 7800 XT (16 GB) |
| CPU | AMD Ryzen 5 7600X |
| OS | CachyOS + Hyprland (switching over soon) |
| Stack | ROCm, llama.cpp, Ollama, ComfyUI |
